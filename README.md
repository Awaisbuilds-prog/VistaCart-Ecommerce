# VistaCart - Full-Stack E-Commerce Platform

VistaCart is a full-stack e-commerce application built with React, Node.js, Express.js and PostgreSQL.

## Features
- Product catalogue and category filtering
- Product search and sorting
- Shopping cart and wishlist
- Product details
- Cash on Delivery checkout
- PostgreSQL database integration
- Order management API
- Email confirmation integration

## Technology Stack
- Frontend: React, Vite, JavaScript, CSS
- Backend: Node.js, Express.js
- Database: PostgreSQL
- Email: Resend

## Setup
1. Create a PostgreSQL database named shopsphere.
2. Import backend/database/schema.sql.
3. Import backend/database/products_seed.sql.
4. Copy backend/.env.example to backend/.env and configure your credentials.
5. Run npm install and npm run dev inside backend.
6. Run npm install and npm run dev inside frontend.
